# LifeOS 人生事务规划工作台

> 单文件 HTML · 纯本地存储 · 零外部 API · 断网也能用

##  项目简介

一个把"项目 / 竞赛 / 课程截止日 + 休闲学习追踪 + 目标管理"装进同一个页面的个人事务规划工作台。**单文件 HTML，无构建依赖、无后端、无外部请求**，所有数据存在浏览器 localStorage。

### 九个视图

| 视图 | 干什么 |
|---|---|
| 今日 | 今日安排、冲突提醒、待办、临近截止、四条人生链条进度 |
| 活动库 | 项目卡片，按链条/分类筛选，带「我为什么想去」 |
| 待办库 | 进行中 / 今日 / 逾期 / 已完成四栏，可实时改进度与内容 |
| 日程 | 年 / 月 / 周 / 日四档，时间+地点+**冲突高亮**，点开即改 |
| 复盘 | GRAI + 4L 两套模板 |
| 语音笔记 | 按住说话，转文字后可一键转成待办或项目 |
| 人生链条 | 文化服务 / 见识世界 / 人际合作 / 性情修养，各自定目标看进度 |
| 每周推荐 | 每周一 10:00 自动检索，点「加入」才进活动库 |
| 花花草草 | 珍藏项目长成植物，**明暗区分已做与待办** |

### 关键机制

- **链接导入**：粘一段公众号/网页文字 → 自动拆出标题、机构、活动时间、报名截止、地点、费用、邮箱/微信、报名要求。活动时间与报名截止是两个独立字段；原文没写的字段显示「缺失」，**不编造**；报名要求自动拆成待办清单。
- **冲突检测**：时间重叠 + 通勤冲突（间隔 <30 分钟且地点不同）都会黄条提醒，但**不阻断保存**。
- **甲方需求洞察**：识别机构类型，推断对方真实诉求与风险提示，给出开场/中段/收尾话术。
- **一键邮件报名**：生成完整邮件正文（主题、动机段、基本信息、附件清单、敬语），调起邮件客户端；微信内自动降级为复制到剪贴板。
- **每周推荐**：每周一自动检索敦煌研究院、大足石刻、中国博物馆协会、ICOMOS China、非遗网、EveryArt、On the Move、UNESCO Silk Roads 等信源，只放可核实的平台。

##  快速开始

**直接使用**：双击 `webapp/index.html`。

**改源码后重新构建**：

```bash
cd webapp
node build.js        # src/ → index.html
node test-lifeos.js  # 跑测试
```

**小程序**：用微信开发者工具导入 `miniprogram/` 目录。
