# 人生事务规划工作台 · 交付总览

## 一、这次做了什么

搭了一个**全新的、独立的工作台**（不是旧招生筛选工具的升级分支，是另一套代码库 `lifeos/`），把你口述的那套需求落成能真正点开用的东西。

单文件 HTML，纯本地存储，**零外部 API、零外部资源依赖**，断网也能用。

## 三、几个关键机制

**链接导入**：粘一段公众号/网页文字 → 自动拆出标题、机构、活动时间、报名截止、地点、费用、邮箱/微信、报名要求。
- 活动时间与报名截止是**两个独立字段**，绝不混为一谈
- 原文没写的字段显示「缺失」，**不编造**
- 报名要求自动拆成待办清单（作品集 → 整理并提交作品集）

**冲突检测**：时间重叠 + 通勤冲突（间隔 <30 分钟且地点不同）都会黄条提醒，但**不阻断保存**。

**甲方需求洞察**：识别机构类型（高校院系 / 文保机构 / 策展团队…），推断对方的真实诉求、他们真正想要的人、你的切入角度、风险提示（比如押金类风险），并给出开场/中段/收尾/禁忌的话术。

**一键邮件报名**：生成完整邮件正文（主题、动机段、基本信息、附件清单、敬语），调起邮件客户端；微信内自动降级为复制到剪贴板。
